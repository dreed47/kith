Import a GEDCOM file

For a file from a relative's genealogy program. Everyone in it comes in as new people and families, linked among themselves; nothing already in the tree changes. You'll see what's in the file before anything is imported, and an import can be undone until someone edits what it brought in.

Getting a file from another site

Each site exports the names, dates, places, relationships, notes and sources. Photos and documents stay behind; upload them here afterwards. Importing the same file twice makes two copies of everyone.

Ancestry

On the Ancestry website (the app can't export), open the tree, then choose Tree settings and Export tree. When it's ready, download it and choose the .zip file here as it is.

MyHeritage

On the MyHeritage website, open Family tree, then Manage trees. Next to the tree, choose Export to GEDCOM. MyHeritage emails you a link; download the file and choose it here.

FamilySearch

FamilySearch has no GEDCOM download for its shared Family Tree. Copy your branch into a desktop program that connects to FamilySearch, such as RootsMagic or Ancestral Quest, then export a GEDCOM file from that program. People still living, and Memories (photos and stories), don't come across.

Geneanet

On your Geneanet tree, open the tree menu and choose Import/export, then export a GEDCOM file.

WikiTree

Use WikiTree's GEDCOM download page (Special:DownloadGedcom) and start from one person, taking their ancestors or descendants. Profiles you can't see are left out. Biographies come in as notes, so check their formatting.

A desktop program (Family Tree Maker, RootsMagic, Legacy, Gramps)

Use File, then Export, and choose GEDCOM. If it asks for a character set, choose UTF-8 so accented letters come through.
